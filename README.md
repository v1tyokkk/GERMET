## ✨ About the Project

**GERMET** — современный landing page для сантехнической компании, разработанный для презентации услуг и формирования доверия потенциальных клиентов.

Основная задача проекта — предоставить пользователю всю необходимую информацию о компании в удобной и визуально понятной форме: ознакомиться с услугами, посмотреть примеры выполненных работ, прочитать отзывы и связаться со специалистами.

Интерфейс разработан с учетом различных размеров экранов и ориентирован на комфортное использование как на компьютерах, так и на мобильных устройствах.

---

## 🚀 Features

- 🔧 **Services** — презентация основных сантехнических услуг
- 🏗️ **Project Gallery** — визуальное портфолио выполненных работ
- ⭐ **Client Reviews** — блок отзывов клиентов
- 🎬 **Media Content** — работа с фото и видео
- 📩 **Contact Form** — форма обратной связи
- 🧭 **Responsive Navigation** — адаптивная навигация
- 🎞️ **Interactive Slider** — интерактивная презентация контента
- 🧮 **Interactive Calculator** — расчет стоимости услуг
- ✨ **UI Animations** — интерактивные элементы и анимации
- 📱 **Responsive Layout** — адаптация под мобильные устройства
